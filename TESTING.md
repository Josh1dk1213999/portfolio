# Portfolio Website Test Plan

All tests must be run on the live GitHub Pages website, not a local file or the GitHub repository preview. Open the deployed site before starting. All Actual Result cells remain **Not Run** until manual testing is performed.

Record the browser, viewport size, date, and observations when documenting results. Any failed test must be fixed, re-run on the updated live site, and documented with the original problem and the re-test result.
