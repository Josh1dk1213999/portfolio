# Joshua Guambana — Engineering Portfolio

A personal portfolio website created for SDET 101 at the New Jersey Institute of Technology. The website showcases my Electrical & Computer Engineering Technology background, technical skills, and Onshape CAD engineering projects from my first semester at NJIT.

- [Live website](https://josh1dk1213999.github.io/portfolio/)
- [Repository](https://github.com/Josh1dk1213999/portfolio)

## Pages

- Home
- About Me
- Projects
- Skills
- Contact

## Featured Engineering Work

The portfolio features Onshape 3D modeling, engineering drawings, and mechanical assemblies:

- Signet Ring
- Motor Gear
- Motor Piece
- Scooter Clamp Section View Drawing
- 3D Cone Section View Drawing
- Scooter Assembly

## Local Viewing

1. Clone or download the repository.
2. Open the portfolio folder.
3. Double-click `index.html` or open it in a web browser.
4. No server, npm, framework, or build process is required.
